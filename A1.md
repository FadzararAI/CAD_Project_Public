# A1: DDR5 Configuration Limitations Report

## Overview

This document describes the modifications made to DDR5 configuration files for compatibility with DRAMSim3 and gem5 simulation framework.

## Problem Summary

DRAMSim3 does not natively support the DDR5 protocol. When attempting to run DDR5 simulations, the following errors were encountered:

1. **Protocol Error** (`configuration.cc:76`): `Unknown/Unsupported DRAM Protocol: DDR5`
2. **Burst Size Mismatch** (`dramsim3.cc:86`): `DRAMsim3 burst size 128 does not match cache line size 64`

## Changes Made

### 1. Protocol Change

**Original:** `protocol = DDR5`
**Modified:** `protocol = DDR4`

**Reason:** DRAMSim3 only supports: DDR3, DDR4, GDDR5, GDDR5X, GDDR6, LPDDR, LPDDR3, LPDDR4, HBM, HBM2, HMC

### 2. Burst Length Change

**Original:** `BL = 16` (native DDR5 burst length)
**Modified:** `BL = 8`

**Reason:**
- DDR5 with BL=16 and device_width=8 gives burst size = 128 bytes
- gem5 cache line size = 64 bytes
- DRAMSim3 requires burst size to match cache line size
- BL=8 × 8 bytes = 64 bytes (matches gem5)

### 3. Config File Format

Original DDR5 configs used incorrect INI format with sections like `[general]`, `[dram_timing]`, `[dram_power]`.

Corrected to standard DRAMSim3 format:
- `[dram_structure]`
- `[timing]`
- `[power]`
- `[system]`
- `[other]`

Also fixed `addr_mapping = roch_2bank` to `address_mapping = rochrababgco` (must be exactly 12 characters).

## Files Modified

- `configs/dramsim3/ddr5/DDR5_16Gb_x8_4800.ini`
- `configs/dramsim3/ddr5/DDR5_16Gb_x8_5600.ini`
- `configs/dramsim3/ddr5/DDR5_16Gb_x8_6400.ini`

## What Is Preserved (DDR5-accurate)

| Parameter | DDR5-4800 | DDR5-5600 | DDR5-6400 |
|-----------|-----------|-----------|-----------|
| Clock (tCK) | 0.417 ns | 0.357 ns | 0.312 ns |
| CAS Latency (CL) | 40 | 46 | 52 |
| Bank Groups | 8 | 8 | 8 |
| Banks per Group | 4 | 4 | 4 |
| tRCD | 40 | 45 | 50 |
| tRP | 40 | 45 | 50 |
| tRAS | 77 | 88 | 96 |
| Voltage (VDD) | 1.1V | 1.1V | 1.1V |

## What Is Compromised

| Feature | Real DDR5 | Our Config | Impact |
|---------|-----------|------------|--------|
| Protocol | DDR5 | DDR4 | Command scheduling differences |
| Burst Length | 16 | 8 | Reduced data per access |
| Sub-channels | 2 | N/A | Not modeled |
